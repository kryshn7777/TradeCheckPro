# Abyssal Tether: VRC checklist (Meta Horizon Store, immersive WebXR PWA)

Snapshot of the build in `public/abyssal-tether-3d/` as of **2026-10-19**. Companion to
[RELEASE.md](RELEASE.md), which has the process, the sources and the owner actions.

- **Status**: `needs-work` = known gap, task below closes it. `unknown` = can only be judged on a
  Quest 3 (or in the Dashboard); task says how. `likely-pass` = the code already does it, still to
  be confirmed on device before submission. "n/a" items are marked `likely-pass` with the reason.
- **Req.** = Meta's marking for immersive Store apps: **R** required, **rec** recommended,
  **retired**; a trailing **?** means the marking was not visible in the excerpt we could read
  (treat as required until you have checked the page). Requirement wording is quoted or closely paraphrased from the Meta VRC pages (URLs in
  RELEASE.md §20); those pages were read through search-engine excerpts because
  `developers.meta.com` is blocked from this sandbox, so re-read each page before you rely on it.
- **Owner** = which agent/file area owns the fix per `CONTRACT3D.md` (game = `src/game.js`,
  `src/main.js`, `index.html`; ui = `src/ui/ui3d.js`; input = `src/input/*`, `src/render/handsView.js`;
  render = `src/render/*`; release = this folder, hosting, Dashboard).

Verdict at a glance: **6 required checks need work before an ALPHA build can pass review**
(Performance.3 startup, Performance.1 measured frame rate, Functional.1 soak, Functional.4 data,
Security.2 permission audit, Privacy.1-4 policy) plus the Asset set; most others already pass in code.
